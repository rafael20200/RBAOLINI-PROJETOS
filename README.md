# RBAOLINI PROJETOS

Portfólio profissional de Rafael Barros Paolini, desenvolvido com HTML5, CSS3, Bootstrap 5 e JavaScript.

## Páginas
- `index.html` — Home com slideshow de projetos em destaque.
- `portfolio.html` — Cards de projetos e modais para vídeos.
- `imagens.html` — Galeria visual.
- `sobre.html` — Apresentação profissional.
- `contato.html` — Contato por e-mail.

## Publicar no GitHub Pages
1. Crie um repositório público chamado `RBAOLINI-PROJETOS` na conta `RBAOLINI`.
2. Envie todos os arquivos mantendo a estrutura de pastas.
3. Em **Settings > Pages**, escolha **Deploy from a branch**.
4. Selecione `main` e `/ (root)`, depois salve.
5. Acesse `https://rbaolini.github.io/RBAOLINI-PROJETOS/`.

## Personalização
Os cards e textos usam os projetos já discutidos: AppProducao 3.0, RBP Webmail, RBP System, App de Assinaturas, Dashboard de Produtividade e Automação de Documentos. As imagens e vídeos estão preparados para receber materiais reais; nenhum vídeo ou screenshot fictício foi apresentado como material original.

Bootstrap 5.3.3 e Bootstrap Icons são carregados por CDN.
